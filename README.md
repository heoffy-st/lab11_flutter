# TaskFlow

**TaskFlow** — мобильное приложение для управления задачами и проектами. Оно помогает создавать задачи, распределять их между участниками и отслеживать ход работы.

Проект разработан на **Flutter**. Данные сохраняются локально на устройстве с помощью **SQLite** и **Drift**.

## Возможности

- **Главная панель** — сводная информация о задачах и проектах.
- **Задачи** — создание, редактирование, поиск, фильтрация и удаление.
- **Проекты** — создание проектов, управление участниками и ролями.
- **Пользователи** — список пользователей и поиск по имени или электронной почте.
- **Комментарии и вложения** — дополнительная информация к задачам и прикреплённые файлы.
- **История изменений** — просмотр изменений статусов задач.
- **Корзина** — восстановление удалённых задач или их окончательное удаление.

## Технологии

| Технология | Назначение |
|---|---|
| Flutter | Разработка интерфейса приложения |

## Запуск проекта

### 1. Установите Flutter

Инструкция: https://docs.flutter.dev/get-started/install

### 2. Склонируйте репозиторий

```bash
git clone https://github.com/heoffy-st/lab11_flutter.git
cd lab11_flutter
```

### 3. Установите зависимости

```bash
flutter pub get
```

### 4. Сгенерируйте файлы Drift

Этот шаг обязателен: Drift создаёт файл `app_database.g.dart`, в котором находятся методы и типы базы данных. Без него проект не соберётся.

```bash
dart run build_runner build --delete-conflicting-outputs
```

### 5. Запустите приложение

Подключите Android-устройство или запустите эмулятор, затем выполните:

```bash
flutter run
```

## Проверка
